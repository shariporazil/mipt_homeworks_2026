# Итоговый проект "GigaVibeMiptCode"

Консольный ИИ-ассистент для общения с языковыми моделями через OpenAI-совместимое API Ollama.

## Возможности

- Интерактивный чат с LLM в консоли
- Потоковый вывод ответов
- Управление контекстом: обрезка по количеству сообщений и по количеству символов
- Системный промпт (задаётся в config.yaml)
- Вставка содержимого файлов через `@::путь::`
- Обработка больших файлов по частям через `/file_chunk`
- Команды: `\q` (выход), `/reset` (очистка истории и экрана)

## Требования

- Python 3.10+
- Ollama

## Инструкция по запуску

1. Установка зависимостей

Для работы приложения установите необходимые библиотеки:

```bash
pip install -r requirements.txt

2. Настройка конфигурации
